# Trail Strength 40+

PWA pessoal de fortalecimento para trail running.

## V4
- Dashboard de sessão com progresso.
- Retomar treino de onde parou.
- Registro de carga e repetições por série.
- Séries individuais com descanso sugerido por bloco.
- Timer de exercício e timer de descanso.
- Histórico de sessões e cargas.
- Tela de progressão do plano (semanas 1–12).
- Funcionamento offline via Service Worker.
- Compatível com GitHub Pages.

## GitHub Pages
Publique a pasta como site GitHub Pages usando `main` e `/ (root)`. O ponto de entrada é `index.html`.
