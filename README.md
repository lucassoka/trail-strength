# Trail Strength 40+ V5

Personal trail-running strength training PWA.

## V5
- Weekly phase selector (weeks 1–12)
- Automatic migration of V4 local data
- Per-set load and reps
- Per-set RPE (1–10) and notes
- Session volume, average RPE and duration in history
- Rest timer with skip option
- PWA/offline cache

GitHub Pages entry point: `index.html`.
